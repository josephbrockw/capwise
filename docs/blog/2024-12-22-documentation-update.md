We've completely restructured the BaseBuild documentation to better reflect the current state of the project.

<!-- truncate -->

## What's New

### Restructured Documentation

The documentation has been reorganized into clear sections:

- **Services** - Dedicated docs for Django API, Next.js, React, and Mobile
- **Development** - Installation guide, CLI tool reference, and contributing guidelines
- **DevOps** - Environment variables and configuration reference

### Next.js Component Library

Added comprehensive documentation for the Next.js component library, organized by category:

- **UI Components** - Button, Input, Checkbox, Select, Toggle, Label
- **Feedback** - Modal, Toast, Alert, Spinner, Skeleton
- **Data Display** - Table, Avatar, Badge, Progress
- **Navigation** - Tabs, Navbar, Breadcrumbs, Dropdown
- **Forms** - FormField, FormGroup, useForm hook
- **Layout** - Container, Stack, Flex, Divider

### Theming Documentation

Full theming documentation for the Next.js app, covering:

- Brand colors with automatic palette generation
- Typography system
- Spacing and layout tokens
- Dark mode configuration

### CLI Tool Documentation

Complete reference for the `bb` CLI tool with all available commands for testing, database management, and Docker operations.

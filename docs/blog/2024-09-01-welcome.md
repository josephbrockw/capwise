## What is BaseBuild?

BaseBuild is a production-ready application template that provides:

- **Django API Backend** - RESTful API with authentication, JWT tokens, email verification, and Stripe payments
- **Multiple Frontend Options** - Next.js (primary), React, and React Native for mobile
- **Developer Tooling** - BB CLI, Docker Compose, automated setup
- **Comprehensive Documentation** - You're reading it!

## Why BaseBuild?

Starting a new project often means spending days or weeks on boilerplate:

- Setting up authentication
- Configuring the database
- Building UI components
- Writing deployment scripts

BaseBuild gives you all of this out of the box, so you can focus on building your actual product.

## Getting Started

```bash
git clone https://github.com/josephbrockw/basebuild.git
cd basebuild
./dev_setup.sh
```

Check out the [Installation Guide](/docs/development/installation) for detailed setup instructions.
